已实现并部署正方形、猫、兔、鱼、船、房子六个图案。按用户补充要求，默认改为单张新照片：识别完成即关闭相机，使用冻结照片计算和显示；失败直接提示，不循环重拍。多帧审查仅为可选调试设置。

## 识别与几何处理

原有色差梯度细化在白片投影阴影附近会跳选边缘，实拍中约每数帧出现一次 3 mm 顶点跳变。七巧板改用掩膜轮廓的整条边鲁棒拟合，现场观测的多数顶点波动降至约 0.2–0.7 mm；原纸片分支保持原方法。

现场七片与理想 100 mm 模板存在轮廓差异，最大顶点拟合残差约 2.64 mm。片型识别使用 3 mm 容差，搬运目标仍为原实测多边形的纯旋转和平移。规划在限定位移内调整目标，实测轮廓之间保留至少 1 mm 间隙；没有缩放碎片，也没有用反射矩阵模拟翻面。

## 实物验收边界

用户已确认本功能沿用原程序的运动方式和标定，`actuation_overrides={}`，直接引用板端已验收配置。只规划验证完成后，M0 状态为 version=1、armed=false、magnet=false、fault=0，随后按计划执行了一片的大三角搬运试验：先校验完整七片方案，再单独测试第一片，测试未修改生产菜单的运动开关。

控制日志记录了 XYZ 使能、Z 抬升、顺时针旋转约 94.8°、返回起点、旋转回零、磁铁关闭和失能，执行器正常退出。但动作后单张照片仍检出七片都在右侧，左侧目标区为空。因此单片实物验收失败，已停止后续整图动作；旋转反馈和桥接 ACK 不能证明 XYZ 实际运动或磁铁吸取成功。没有将最近的其他源碎片误记为目标精度测量结果。

证据见 [单片结果](first-piece-result.json)、[测试使用的完整方案](first-piece-plan.json) 和 [动作后照片](first-piece-after.png)。七片前后质心的最小距离整体匹配中，最大变化仅 0.231 mm，支持“源区没有完成搬运”的判定。M0 再次查询仍为未使能、磁铁关闭、fault=0。需根据现场观察区分 XY/Z 未动作、未吸起或其他机械问题；新模式继续 `motion_verified=false`，不自动重试运动。六图案各三次搬运及 2 mm / 3° 精度尚未验收。

XPR、BD、bitstream、设备树和启动镜像未随本功能更新；板卡未重启。SSH 使用 A7A 网口跳板，主机 RSA 公钥通过直连串口核对；root 家目录属主修正及公钥接入记录见 [操作说明](../../tangram.md)。
