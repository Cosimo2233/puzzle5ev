# 搬运中机械角阈值调整（2026-10-27）

现场最近一次七巧板任务在第六片搬运时失败：顺时针目标 199.3°，单圈反馈约 201.0°，偏差 1.7°。底层多圈位置等待已通过，执行层追加的 1° 单圈复核仍报错，继而进入消磁、停止和失能清理，造成带片时释放。此前也出现过 1.1° 偏差触发的同类中止。

按用户要求调整共用运动执行器：

- 启动初始化回零、每片吸取前仍读取有效机械角，执行 1° 零位检查；超限或非有限反馈禁止开始吸取。
- 搬运中的顺时针动作、片间/末片回零及任务收尾不再追加机械单圈角的 1° 中止条件。
- 仍调用原旋转接口 `wait=True`，保留多圈坐标稳定到位等待、通信/协议错误、超时、XY 完成等待、Z 时序和异常清理。
- 下一片吸取前如果零位仍偏差超过 1°，会在磁铁未吸取新片时拒绝继续；不会因为已释放后的回零单圈偏差跳过该前置检查。

模拟执行器新增/调整回归验证：199.3° 目标反馈偏差 1.7° 时完成放置；末片回零反馈 358.9° 时正常收尾；下一片拾取前 358.9° 仍被拒绝；启动异常、通信及超时继续触发原清理。
