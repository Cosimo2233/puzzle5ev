# 扑克牌花纹分割现场修正

记录日期 2026-10-21；板端原始时钟仍为 2026-10-20。实物是蓝色 A4 上的四片 J 扑克牌。本次没有发送运动或电磁铁命令。

## 原因与修正

原参数 `EC_BLUE_RATIO_Q8=275, EC_BLUE_MIN=45` 将蓝灰色、受蓝光影响的深色印刷误判为蓝底。部分印刷延伸到切边，产生与外部连通的缺口，因此已有 `RETR_EXTERNAL` 忽略内部孔洞的逻辑无法补救；外轮廓出现多余顶点、碎片被拆成额外连通域。不是 PL 协议故障，也不是单纯靠时序平滑可以修复的问题。

随机模式新增独立参数：

```ini
TASK2_BLUE_RATIO_Q8=320
TASK2_BLUE_BACKGROUND_FRACTION_Q8=218
```

在透视校正后的图像上，PS 跳过外围 8 像素，以 12 像素步长稀疏采样。符合蓝色比例的样本至少占 40%，才使用其 B 通道中位数的 `218/256` 作为当前帧蓝底亮度门槛，最低仍为原 `EC_BLUE_MIN=45`。没有足够蓝底时明确拒绝该帧，不复用旧门槛。采样不生成全幅 CPU 掩膜；整幅阈值、3×3 滤波和形态学仍交给原 PL 核。使用现有逐帧寄存器/IOCTL，不改 HLS、bit/HWH，不重启板卡。

默认关闭自适应。固定模式仍为 `[ratio=275, min=45, fraction=0]`。随机模式为 `[320,45,218]`；共享预处理器按每个调用方的模式提交参数。没有使用凸包、大核闭运算，也没有放宽几何质量、稳定性、规划或旋转门槛。

测试中相机/工作台相对位置发生变化，旧参考四角超出搜索范围，30 帧被 A4 定位拒绝。用户恢复角度后仍有约 50 像素平移，重新定位得四角 `(308.03,99.11), (1127.07,110.79), (1115.58,681.65), (302.61,678.11)`，边缘拟合残差 0.48 px。只更新两个任务的图像参考四角，保持搜索带 0.04、每帧真实边线检查和机械坐标/等待时间不变。

## 验证结果

| 验证 | 结果 |
|---|---|
| 最初 12 帧实拍 PL 回放 | 11 帧正常曝光均识别四片；启动帧因蓝底样本不足拒绝 |
| 原始正常帧顶点数 | 3、5、4、4，保持真实外轮廓 |
| 最终参数新采 30 帧 | 30/30 四片；建立六帧窗口后 25/25 输出稳定结果 |

| 正式部署后再采 10 帧 | 10/10 四片；第 6～10 帧稳定输出，蓝底采样合计 13.57 ms |
| 真实输入 CPU/PL 掩膜 | 11 帧回放及 30 帧实时全部逐像素相同 |
| 41 帧实拍亮度缩放 | 0.6、0.8、0.9、0.95、1、1.05、1.1 倍，共 287 次 CPU 检测均四片 |

| 当前扑克牌只求解 | 6 帧稳定审查通过、0 无效帧；随机搜索未生成可执行方案 |

只求解日志：稳定审查约 4.61 秒，随机搜索约 32.60 秒后报 `recovery exhausted without a machine-executable random candidate`。实际 PL 配准 2457 项、61 批，CPU 数值回退 0 次；6 次预处理的稀疏亮度采样合计约 8.33 ms（约 1.39 ms/帧）。本次**不能声称随机整次任务成功，也未达到随机完整方案 P95 ≤20 秒的实物验收**；搜索失败的具体几何原因尚未定位。

主机视觉、配置隔离、共享模式切换和传输测试：最终针对性检查 95 项通过；扩展配置检查共 116 项通过。另两项现有配置快照测试仍期待最短边合并值 20，而当前配置分别为 8/12；用上一版 wheel 重跑同样失败，已确认不是本次引入，未改动这些既有配置或断言。实拍回归图为 `sw/tests/fixtures/vision/poker-j-blue-print.png`，来自本次摄像头原始第 5 帧的 A4 校正结果；不是真实尺寸标注数据。额外合成回归覆盖蓝灰印刷接触外边、真实凹角及片间间隙。


`production-before/` 保存原应用、求解器、配置和启动入口。第一次发布因检查子进程缺少 `EC_PL_BITSTREAM` 自动回滚；v2 在停止菜单前校验硬件文件，并在明确设置同一硬件路径后重新部署。只重启菜单服务，菜单开机自启、运动权限、机械标定、求解器和加载硬件保持原值。

部署核对：87 个应用文件与 wheel 逐字节一致；固定/随机有效参数分别为 `[275,45,0]`、`[320,45,218]`；求解器源码与备份相同；菜单配置及启动入口字节不变；boot ID、bit 哈希保持不变。详细检查结果为 `cards-20261021/deployment-verification.json`。当前菜单 PID 3954，处于空闲，未自动开启任务。

回滚（菜单退出任务和预览后）：

```sh
. /opt/ec26e/env.sh
unset PYTHONPATH
python /opt/ec26e/releases/cards-20261021-v2/install_cards_release.py \
  --release /opt/ec26e/releases/cards-20261021-v2 --rollback --apply
```

实拍、掩膜和详细 JSON 位于本机 `build/axu5ev/cards-20261021/` 及板端 `/opt/ec26e/validation/cards-20261021/`；汇总证据见同名子目录。参数只验证了当前蓝底和这张牌的印刷范围。亮度缩放不是实际换灯测试；过曝饱和、强烈局部阴影、与底板接近同色同亮度的印刷仍需新场景验证。
