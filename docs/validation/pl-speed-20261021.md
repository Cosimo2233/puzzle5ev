# AXU5EV-P 固定四片与随机 2～4 片提速验证

记录日期：2026-10-21。板卡原始时钟仍为 2026-10-20，原始日志时间保留，不据此推断另一次测试。

## 状态与计时口径

软件、真板 PL 数值验证和回放测试已完成，发布状态见本文末尾。本轮所有自动验证只运行识别、求解及计划检查，没有发送运动或电磁铁命令。机械标定、落位、运动顺序、转轴策略和等待时间沿用用户已确认成功的配置。

平台：AXU5EV-P / XCZU5EV-2SFVC784I，AArch64 Linux 5.4.0-xilinx-v2020.1，CPython 3.11.17；测试时 CPU governor 为 userspace，读回频率 1066666 kHz。OpenCV 与 BLAS 采用单线程，板端任务串行执行。

三类结果分开记录：

- **纯几何**：同一批毫米顶点输入，包含求解与 PS/PL 数据传输，不包含图像。
- **固定录制回放**：同一组已保存相机画面，包含文件解码、A4 校正、六帧且至少两秒的连续审查、检测、传输、求解和输出。
- **随机合成回放**：90 张合成相机图，每种片数 30 张，其中 45 张含模拟扑克内部花纹；覆盖旋转、三档亮度、凹角、浅角、近似对称及不同连接形式。重复合成帧不能证明真实相机时间稳定性。

回放采用菜单同一模块预加载函数，模块就绪后开始计时，测到子进程退出，包含约 0.5～0.6 秒退出开销；日志另记录到方案生成的耗时。预加载不打开硬件、不保留旧观测、不自动开始任务。立即在预加载完成前启动可能包含额外导入时间。

**现场固定四片当时触碰识别区边界，用户暂时无法重新摆放，因此真实相机 P95 尚未完成；随机实物样品尚未提供。以下数据不能替代正常摆放下固定 ≤8 秒、随机 ≤20 秒的现场验收，也不替代实际搬运不重叠、对应顶点距离 ≤20 mm、任务 ≤120 秒的机械验收。**

各组 30 次；时间单位为秒，格式为“中位数 / P95”。原 CPU 随机四片时间包含失败耗时，不能当作成功解耗时。

| 模式 | 原 CPU 成功数 | 原 CPU | 优化 CPU 成功数 | 优化 CPU | 优化 PL 成功数 | 优化 PL |
|---|---:|---:|---:|---:|---:|---:|
| 固定四片 | 30/30 | 2.177 / 2.230 | 30/30 | 2.100 / 2.141 | 30/30 | 1.837 / 1.911 |
| 随机两片 | 30/30 | 2.003 / 2.244 | 30/30 | 1.842 / 2.158 | 30/30 | 1.829 / 2.154 |
| 随机三片 | 30/30 | 4.161 / 6.728 | 30/30 | 3.573 / 3.964 | 30/30 | 3.583 / 3.944 |
| 随机四片 | 12/30 | 29.087 / 29.626 | 30/30 | 6.081 / 10.328 | 30/30 | 6.073 / 10.287 |

随机几何提速主要来自候选剪枝、缓存、有效方案后的停止以及数值稳定的分支排序；当前小批次 AXI-Lite 配准的传输开销抵消了大部分核内加速。不能将全部算法收益归功于 PL。

|---|---:|---:|---:|---:|
| 固定四片 | 2340 | 61 | 30 | 0 |
| 随机两片 | 403 | 30 | 0 | 0 |
| 随机三片 | 1912 | 160 | 0 | 0 |
| 随机四片 | 14239 | 1052 | 0 | 0 |

独立检查全部导出成功方案的刚体变换、有限有效多边形、目标区范围及无重叠：原 CPU 102/102，优化 CPU 120/120，优化 PL 120/120。求解器内部完整执行检查仍启用，未降低置信度或几何门槛。

| 随机两片合成回放，优化 PL | 30/30 | 5.252 | 5.577 |

上述回放方案另经独立检查，固定 CPU/PL 各 30/30、随机 PL 90/90 全部通过。原 CPU、优化 CPU、优化 PL 三方对照已覆盖纯几何；尚未完成三方真实相机端到端对照。

图像链路中每组 30 次均实际处理 180 帧 PL 图像。固定配准请求 2340、任务批数 60、间隙扫描 30；随机两片为 404/30、三片 2087/162、四片 15849/1011（请求数/任务批数），随机间隙扫描均为 0。`PL_PERFORMANCE` 的任务差值不含每个新进程初始化时的一个空批探测；该探测不含配准点，请求数不受影响。全部数值 CPU 回退和固定近似平局 CPU 重拟合计数均为 0。

固定 PL 回放每项任务的阶段中位数：读取/解码 0.420 秒，A4 校正 2.235 秒，检测 0.795 秒（其中 PL 预处理 0.215 秒），稳定审查计算 0.131 秒，求解 1.908 秒。预处理包含在检测内，不能重复相加；稳定条件仍是六个不同序号且跨度至少两秒。完整日志保留逐项传输与等待时间。

90/90 合成场景识别数量正确且稳定检测输出一致，CPU 与 PL 的 90/90 预处理掩膜逐像素完全一致。单独预处理的中位数（包含 PL 打包、DMA、输出复制）：

| 后端 | 墙钟耗时 | PS 进程 CPU 时间 |
|---|---:|---:|
| CPU | 43.07 ms | 43.05 ms |
| PL | 34.44 ms | 29.44 ms |

因此该阶段墙钟减少约 20%，PS CPU 时间减少约 32%。A4 透视校正、轮廓提取、精确顶点和完整几何检查仍由 PS 执行。额外的 cacheable BGRA 暂存再复制实测未获益（打包中位数 27.50 ms，对比现有 26.38 ms），未引入该改动。

## 数值、异常与主机检查

- 真板配准批量边界 0/1/63/64/65/129，共 322 项、含探测 9 批；相对 CPU 最大参数误差 0.000156327，低于既有 0.002 容差，数值回退 0。
- 真板间隙核 401 个采样，相对 CPU 最大误差 0.000003217 mm，低于既有 0.02 mm 保护带；仍由 PS 最终复核。
- 真板 8 个无效输入全部拒绝：固定缺片、随机单片/五片、无合法矩形、短边、空工作区、接触边界和 A4 遮挡。边界用例包含两片，实际拒绝原因为“纸片接触工作区边界”，不是片数不足。
- 真板菜单预加载进程验证通过：就绪时文件描述符仅为请求管道与日志，未打开相机、PL 或运动设备；显式派发只求解命令后复用同一 PID，完成有效方案，未发送运动命令。
- 主机异常注入覆盖 DMA/配准超时、序号错误、NaN 和批次结果长度错误；没有故意破坏正在使用的真板硬件来制造故障。
- 应用相关回归 131 项及 13 子测试通过；菜单预加载与安装回滚测试 6 项通过。求解器相关回归 30 项及 9 子测试通过。
- 全仓库并非全绿：继承的求解器测试仍期望固定布局宽 100 mm 和最小间隙 5 mm，而既有成功配置的留缝布局为约 111.831 mm、4.56965 mm；基线也失败。应用另有旧配置断言，以及 Windows 缺少 fcntl/Tk、符号链接权限和旧部署夹具等环境失败。未通过改动机械策略来迎合这些旧断言。
