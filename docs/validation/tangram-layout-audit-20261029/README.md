## 独立参考依据和测试

独立求解器新增 `tests/fixtures/tangram-reference-layouts.json`，保存从用户参考图独立采样的七片像素顶点和图案出处；这些像素绝不用于运动坐标。`tests/test_tangram_reference_layouts.py` 对每个标准模板只拟合一个整体显示尺度和平移，再逐片比较边界，允许同形三角互换，不允许各片任意移动来迎合参考图。名称的中文映射另有独立断言。

截图本身有描边、压缩、轻微拉伸和人工采点误差，参考比较门槛为图案长边的 5%，仅用于捕获拼法和身份错误；不能当作毫米定位精度。修正后十一项截图比较的最大边界偏差约为参考图长边的 0.6%–3.3%，正方形另由精确几何测试覆盖。详见 [修正前后比较](reference-checks.json)。将同一检查运行于改动前 `5b16154` 的求解器，猫、兔、鱼、船、房子、鸟、海豹七项失败；修正后全部通过。
