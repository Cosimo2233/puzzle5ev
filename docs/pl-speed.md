# 固定四片与随机拼图提速

适用工程为 AXU5EV-P `puzzle5ev`；机械标定、固定落位、运动顺序和等待时间保持成功测试时的设置。

2026-10-21 已完成软件及板端回放验证并部署 `speed-20261021-v2`。固定录制回放 P95 6.133 秒，随机 2/3/4 片合成回放 P95 5.577/7.683/14.920 秒，每组 30/30 成功。真实相机重新摆放后的计时及随机实物验收待补，详见 [验证与回滚记录](validation/pl-speed-20261021.md)。

## PS/PL 分工

相机经 USB/PS 采图，PS 定位 A4、透视校正，再通过 DMA 调用 PL 分割、滤波和形态学处理。PS 用原图精修轮廓和顶点，检查稳定性。

A4 色差计算用数学等价的单通道运算，减少整帧浮点转换和复制。后续帧以前一帧角点作为搜索种子，但必须重新拟合当前帧的四条边并通过完整几何、纸色和明暗检查；失败时使用当前帧重新粗定位，绝不返回旧单应矩阵作为新观测。

固定与随机共用 `RigidFitBackend.fit_batch`。随机边链先按长度、弦长筛选，再按最多 64 项提交；四向连接候选也通过该接口拟合实际碎片位姿。完整边匹配优先，闭合矩形进入后续验证；未找到时保留通用 T 结点、边链及恢复搜索。PS 始终负责拓扑、重叠、间隙及完整执行检查。四凸片间隙 PL 核只用于固定模式。

复用已有 bit/HWH、ABI、设备树和 HLS 核。AXI-Lite 保持对齐的 32 位访问，只传输配准请求实际使用的点。图像输出写入调用方缓冲区，不暴露复用中的 DMA 内存。超时、ABI 或完成序号错误终止当次任务，不返回旧结果。

## 稳定审查与随机规则

任务 JSON 用 `continuous_review: true`、`minimum_stable_frames: 6` 启用连续审查；机器环境中两个 `TASK*_REVIEW_CYCLE_SECONDS` 均设为 2。必须同时满足六张不同的新帧、至少两秒、现有毫米级工作区及顶点阈值。失败或场景移动重新累计，相对窗口首帧比较以排除缓慢漂移。正式任务不再叠加另一轮六帧预热，预览仍可聚合六帧。

随机部署启用 `planning.competition_rules: true`：2～4 片、3～5 边、最短边 20 mm，按端点观测误差处理临界尺寸；结构矩形宽 90～120 mm、高 50～90 mm，每片一整条原始边属于外边界。尺寸检查保留现有观测误差容差，留缝后的落位还需通过执行检查。

纯白和扑克碎片均只按形状求解。外轮廓提取忽略内部印刷孔洞，不用凸包抹掉凹角。随机浅角尝试更精细的近似，但必须满足边线残差 ≤0.35 mm、IoU ≥0.96、长边支持，以及角深度至少为残差六倍等证据。固定四片质量门槛不变。

## 计时与复现

日志中 `TASK_PERFORMANCE` 包含采图、透视校正、检测、稳定审查、求解、总耗时、菜单确认到方案耗时，以及 `vision_pl` 实际帧数和 DMA 开销。`SOLVER_PERFORMANCE` 包含搜索、间隙、最终复核；`PL_PERFORMANCE` 包含有效请求数、批数、扫描数、数值回退和传输耗时。

`FIXED_FIT_PERFORMANCE` 单独记录特征提取、批量配准、总候选耗时及近似平局时的 CPU 重拟合次数；`RANDOM_FIT_PERFORMANCE` 记录随机边链的请求数、调用数及配准时间。硬件计数来自驱动，不能用这些逻辑调用数替代实际 PL 工作量。

菜单 `warm_tasks: true` 时预先启动一个只导入算法模块的进程，等待显式确认后才读取配置、打开设备和执行任务；完成后进程退出。取消沿用原任务进程的 SIGINT 清理流程。预加载不保存旧画面或旧方案，也不自动执行任务。`benchmark_pipeline.py --warm-start` 采用同一预加载函数，在模块就绪后计时，结果标为 `*_dispatch_to_plan`；不带此选项仍测冷启动 `*_process_to_plan`。两种数据不能混为同一计时口径。

预处理包含在检测内，PL 求解包含在求解内，嵌套阶段不可重复相加。目标是正常摆放下固定 P95 ≤8 秒、随机 P95 ≤20 秒。纯几何、合成图、录制画面和真实相机的测量分别记录；录制回放的文件解码时间不能当作真实采图时间。

`deploy/axu5ev/benchmark_speed.py` 比较同一几何输入；`benchmark_pipeline.py` 每次启动独立进程并只求解；`make_synthetic_scenes.py`、`validate_scenes.py` 生成并检查带凹角、浅角、旋转、亮度变化和内部印刷的合成场景。脚本不执行运动。

## 部署与回滚

三个计算后端设为 `pl` 时，需同时设置 `EC_PL_ACCESS=linux`、`EC_PL_BITSTREAM`，指向本次启动已验证的成对 bit/HWH。随机自动跳过四凸片间隙核。菜单配置决定正式任务后端，开机只显示菜单。

发布前备份应用、求解器、任务 JSON、机器环境及菜单配置。回滚需恢复整套软件和配置。保持现有运动权限和机械参数，自动验收只求解。随机实物样品尚未提供，实物识别和搬运仍需单独验收。

`install_speed_release.py --release /opt/ec26e/releases/<版本> --apply` 在全局任务锁内备份并安装，保留机械参数和菜单运动权限，只重启显示/菜单服务，不重载 PL。同一目录加 `--rollback --apply` 恢复完整备份。默认不带 `--apply` 只输出拟执行的修改。
